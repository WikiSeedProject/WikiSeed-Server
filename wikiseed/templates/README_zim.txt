Contents
--------
This torrent contains Kiwix ZIM archives for the project, language, scope,
and period identified in SOURCES.json. ZIM files are pre-rendered offline
HTML archives that can be browsed without an internet connection.

How to use
----------
- kiwix-serve: ships with Kiwix. Run `kiwix-serve --port=8080 file.zim` and
  open http://localhost:8080 in a browser.
- Kiwix desktop & mobile apps: https://kiwix.org
- WikiSeed documentation: https://wikiseed.app
